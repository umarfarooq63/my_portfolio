# Umar Farooq — Personal Portfolio Website

A responsive personal portfolio built with **HTML5, CSS3 and vanilla JavaScript** for the Personal Portfolio Website project.

## Included project features

1. Home section with name, avatar, introduction and navigation.
2. About Me section.
3. Education timeline.
4. Technical and non-technical skills with progress bars.
5. Project cards.
6. Hobbies and interests.
7. Achievements section (ready for real certificates/awards).
8. Contact details and JavaScript form validation.
9. Dark mode / light mode toggle (preference saved in browser).
10. Interactive navigation with active-section highlighting and smooth scrolling.
11. Responsive layouts for desktop, tablet and mobile.

## Run the website

1. Extract the ZIP file.
2. Open the `personal-portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit the content described below before submitting.

## Personalise before submission

- Replace `your.email@example.com` with your real email address.
- Replace the GitHub and LinkedIn links with your own profile URLs.
- Add your previous school/PU college name and dates in the Education section.
- Check the skill percentages and adjust them to your actual skill levels.
- Edit the hobbies so they accurately describe you.
- Add genuine certificates, workshops, awards or hackathon details if you have them.
- Replace the sample/future project card with a project you have actually completed.
- Optionally replace the initials avatar with your own profile photo.

## GitHub submission

Create a new public repository on GitHub, for example `personal-portfolio`.
Upload `index.html`, `style.css`, `script.js` and this `README.md` (or upload the extracted folder contents).
Then submit your repository URL to your instructor.

## Important notes

- The contact form validates input in the browser. As the assignment notes, it does not send email without a backend or email service.
- Skill percentages are editable examples, not verified test results.
- Do not claim certificates, awards or completed projects unless they are genuine.
